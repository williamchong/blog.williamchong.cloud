# Random tools I wrote

- [CBOR to JSON Converter](https://cbor.williamchong.cloud) - Convert CBOR (Concise Binary Object Representation) format to human-readable JSON format
- [Bech32 Wallet Address Converter](https://bech32.williamchong.cloud) - Convert cryptocurrency wallet addresses in Bech32 format
- [Should I take (Hong Kong) Taxi?](https://shoulditake.taxi) - A tool to calculate Hong Kong taxi fare using open data, because Google Map somehow removed that feature
- [Medium Backdating Tool](https://medium-backdate.williamchong.cloud) - Generate URLs that allow easy backdating of Medium stories
- [NIKKE Arena Planner](https://nikke.williamchong.cloud) - PVP team recommender for NIKKE: Goddess of Victory — select your roster, get optimized 5v5 and 15v15 teams with burst timing analysis
- [HK Traffic Sign Map](https://hk-signs-map.williamchong.cloud) - Interactive map of Hong Kong traffic signs from Transport Department open data, rendered with MapLibre GL and PMTiles vector tiles
- [愛·回家之開心速遞 劇集導航](https://comehomelovelb.williamchong.cloud) - Filterable episode catalog for the 2,800+ episode TVB sitcom — find episodes to rewatch by character, story line, festival, cameo or writer, plus community up/down voting to sort by score. [Shared on Threads](https://www.threads.com/@wlchhk/post/Db452v9lMtO) to 41.9K views and 1.3K likes
- [PrayRequest](https://github.com/apps/prayrequest) - A GitHub bot that comments a context-matched Bible verse on every Pull Request. 合併之前，先讀一段。
- [NoSleep](https://nosleep.williamchong.cloud) - A simple tool to prevent your computer from going to sleep
- [e-ink-sim](https://chromewebstore.google.com/detail/e-ink-simulator-extension/bebaiaaembehfnncpeojeeoepdblmemk) - A Chrome extension that simulates e-ink display in your browser — 2nd Runner Up (Bronze Trophy) at the [first AWS AI Hackathon Hong Kong](https://aws.amazon.com/tw/local/hongkong/media-highlight/aws-ai-hackathon/) ([Devpost writeup](https://devpost.com/software/e-ink-sim))
- [Threads Country Flags](https://chromewebstore.google.com/detail/threads-country-flags-%E2%80%93-s/dhajlehnjkhbdheoogoefgacjpkajjoe) - A Chrome extension that adds country flags to Threads profiles based on their location — a Google Featured extension

# Libraries

- [minimax-speech-ts](https://github.com/williamchong/minimax-speech-ts) - TypeScript SDK for the Minimax Speech API, with streaming support and typed error handling
- [nuxt-gre-pixel-module](https://www.npmjs.com/package/nuxt-gre-pixel-module) - Nuxt 2 module for Google Retail Event pixel tracking
- [epubcheck-ts](https://github.com/williamchong/epubcheck-ts) - TypeScript wrapper for EPUBCheck validation
- [epub.ts](https://github.com/williamchong/epub.ts) - TypeScript library for parsing EPUB files
